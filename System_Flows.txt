1. APPLICATION INITIALIZATION FLOW
================================================================================

START → main() in app.py
  |
  ├─→ LOAD SETTINGS
  |     └─→ load_settings() from config/settings.yaml
  |           ├─→ Determine UI_Type (Qt or Tkinter)
  |           ├─→ Board configuration (Type, Port, BaudRate, simulation)
  |           └─→ Read measurement parameters, timeouts, thresholds
  |
  ├─→ SELECT UI TYPE
  |     |
  |     ├─→ IF UI_Type == "Qt":
  |     |     └─→ Launch Qt UI (future feature)
  |     |
  |     └─→ IF UI_Type == "Tkinter":
  |           └─→ Continue with Tkinter initialization
  |
  ├─→ LOAD CONFIGURATION FILES
  |     ├─→ load_settings() → settings dict
  |     ├─→ get_board_pin_map() → pin_map dict (from pin_map.json)
  |     └─→ get_board_pin_config() → board_config dict (from board_pin_config.json)
  |
  ├─→ HARDWARE INITIALIZATION (BEFORE UI)
  |     └─→ initialize_hardware(settings, log_callback=_buffer_log)
  |           |
  |           ├─→ Check Board->Type from settings
  |           |     ├─→ "ControllinoMega" / "ControllinoMini"
  |           |     ├─→ "ArduinoUno" / "ArduinoMega"
  |           |     └─→ "none" → Return None (no hardware)
  |           |
  |           ├─→ Create ControllinoIO instance
  |           |     ├─→ Open serial port (COM5, 115200 baud)
  |           |     ├─→ Wait 2 seconds for Arduino reset
  |           |     ├─→ Clear input buffer
  |           |     ├─→ Send ping command '?'
  |           |     ├─→ Wait for "OK" response
  |           |     └─→ IF fail AND simulation=True: Continue in no-connection mode
  |           |
  |           ├─→ Load connector mapping (Excel file)
  |           |     └─→ Read connector_Address_map.xlsx
  |           |
  |           └─→ RETURN hardware object or None
  |
  ├─→ CREATE TKINTER ROOT WINDOW
  |     └─→ root = tk.Tk()
  |
  ├─→ CREATE MAIN WINDOW (UI Layer)
  |     └─→ app = MainWindow(title="HW Tester")
  |           |
  |           ├─→ Configure Window (title, state='zoomed')
  |           |
  |           ├─→ Configure Grid Layout (3 rows):
  |           |     ├─→ Row 0: PinTableView (weight=3)
  |           |     ├─→ Row 1: OperationalPanel (weight=0)
  |           |     └─→ Row 2: LogView (weight=1)
  |           |
  |           ├─→ Initialize State Variables:
  |           |     ├─→ connected = False
  |           |     ├─→ running = False
  |           |     ├─→ running_ibit = False
  |           |     ├─→ http_server_process = None
  |           |     └─→ next_event = threading.Event()
  |           |
  |           ├─→ CREATE UI COMPONENTS:
  |           |     |
  |           |     ├─→ PinTableView (Treeview widget)
  |           |     |     └─→ Columns: Id, Type, Power_Expected, Power_Input,
  |           |     |         Pullup_Input, Pullup_Expected, Logic_Input,
  |           |     |         Logic_Expected, Test_Result, Voltage, Message
  |           |     |
  |           |     ├─→ OperationalPanel (Control buttons)
  |           |     |     ├─→ Load, Keep-Alive, Next, I-BIT
  |           |     |     ├─→ Test, Test All, Stop T, Stop I-BIT
  |           |     |     ├─→ Report, Doc, Clear Log
  |           |     |     └─→ Settings dropdowns (HW, Simulate, IOBox, etc.)
  |           |     |
  |           |     └─→ LogView (ScrolledText widget)
  |           |           └─→ Color-coded logging (INFO, SUCCESS, WARNING, ERROR)
  |           |
  |           └─→ Flush buffered initialization logs to LogView
  |
  ├─→ INITIALIZE CORE COMPONENTS (Business Logic)
  |     |
  |     ├─→ Measurer (Voltage measurement)
  |     |     └─→ Measurer(hardware_io=hardware, settings=settings)
  |     |
  |     ├─→ PinPulser (Keep-alive / heartbeat)
  |     |     └─→ PinPulser(hardware_io=hardware, settings=settings)
  |     |
  |     ├─→ UDPCardManager (IO card control)
  |     |     ├─→ Create enabled UDP cards (7 cards, C1-C7)
  |     |     ├─→ Start communication threads
  |     |     ├─→ Bind to UDP ports for send/receive
  |     |     └─→ IF binding fails: Display error messagebox
  |     |
  |     └─→ TestHandle (Test execution logic)
  |           └─→ TestHandle(hardware, settings, pin_map, board_config,
  |                          measurer, card_manager, log_callback)
  |                 ├─→ Store references to all dependencies
  |                 ├─→ Initialize control flags (running, running_ibit)
  |                 └─→ Share threading event (next_event)
  |
  ├─→ SET CLOSE HANDLER
  |     └─→ root.protocol("WM_DELETE_WINDOW", app.on_closing)
  |
  └─→ START EVENT LOOP
        └─→ app.run() → root.mainloop() → Application Running

2. PIN CONFIGURATION LOADING FLOW
================================================================================

USER CLICKS "LOAD" BUTTON:
  app.on_load()
    ↓
  Open File Dialog (select Excel file)
    ├─→ Default folder: tests/DB/
    ├─→ File types: *.xlsx, *.xlsm
    └─→ User selects test file
    ↓
  load_connector_from_excel(filepath)
    |
    ├─→ Open Excel workbook (openpyxl)
    |
    ├─→ Read "Connectors" worksheet
    |
    ├─→ FOR each row (starting row 2):
    |     |
    |     ├─→ Parse pin data:
    |     |     ├─→ Id, Type, Power_Expected, Power_Input
    |     |     ├─→ Pullup_Input, Pullup_Expected
    |     |     ├─→ Logic_Input, Logic_Expected
    |     |     ├─→ Pair, Analog_Measure, Card_Enable_List
    |     |     └─→ Test_Result, Voltage, Message (initially empty)
    |     |
    |     ├─→ Create Pin object
    |     |     └─→ Pin(id, type, power_expected, power_input, ...)
    |     |
    |     └─→ Append to pins list
    |
    └─→ RETURN List[Pin]
    ↓
  app.pin_table.set_pins(pins)
    |
    ├─→ Clear existing table rows
    |
    ├─→ FOR each pin in pins:
    |     └─→ Insert row into Treeview widget
    |           └─→ Display: Id, Type, Power_Expected, Power_Input, etc.
    |
    └─→ Enable Test buttons (Test, Test All)
    ↓
  Log success message: "Loaded {count} pins from {filename}"

EXCEL FILE STRUCTURE:
  Worksheet: "Connectors"
  Columns:
    - A: Id (e.g., "J1-1", "J2-15")
    - B: Type (e.g., "Power", "Pullup", "Logic", "Out")
    - C: Power_Expected (voltage value or "High"/"Low")
    - D: Power_Input (e.g., "C2_AO2V10", "none")
    - E: Pullup_Input (e.g., "C3_DO12")
    - F: Pullup_Expected (voltage or "High"/"Low")
    - G: Logic_Input (e.g., "C4_DO5")
    - H: Logic_Expected (voltage or "High"/"Low")
    - I: Pair (associated pin for measurement)
    - J: Analog_Measure (analog port number, e.g., "A0")
    - K: Card_Enable_List (card enables, e.g., "C1_DO1,C2_DO2")

3. TEST EXECUTION FLOW (POWER/PULLUP/LOGIC/RELAY TESTS)
================================================================================

3.1 SINGLE PIN TEST FLOW:

USER SELECTS PIN AND CLICKS "TEST":
  app.on_test()
    ↓
  Get selected pin from pin_table
    ↓
  IF no pin selected:
    └─→ Show warning messagebox → RETURN
    ↓
  Set running = True
    ↓
  Run test in background thread
    ↓
  threading.Thread(target=run_test).start()
    |
    ├─→ test_handler.running = True
    |
    ├─→ Clear pin's previous test result
    |
    ├─→ DETERMINE TEST TYPE based on pin.Type:
    |     |
    |     ├─→ IF "Power":
    |     |     └─→ test_handler.run_power_test(pin)
    |     |
    |     ├─→ IF "Pullup":
    |     |     └─→ test_handler.run_pullup_test(pin)
    |     |
    |     ├─→ IF "Logic":
    |     |     └─→ test_handler.run_logic_test(pin, pin_table_rows)
    |     |
    |     ├─→ IF "Relay" or "Fuse":
    |     |     └─→ test_handler.run_relay_test(pin)
    |     |
    |     └─→ IF "Short":
    |           └─→ test_handler.run_short_test(pin)
    |
    ├─→ Update pin's test result:
    |     ├─→ pin.test_result = "PASS" or "FAIL"
    |     ├─→ pin.voltage = measured_voltage
    |     └─→ pin.message = result_message
    |
    ├─→ Update UI (pin_table row):
    |     ├─→ Set Test_Result column (green "PASS" or red "FAIL")
    |     ├─→ Set Voltage column
    |     └─→ Set Message column
    |
    ├─→ set running = False
    |
    └─→ Log completion message

3.2 TEST ALL FLOW:

USER CLICKS "TEST ALL":
  app.on_test_all()
    ↓
  Get all pins from pin_table
    ↓
  IF no pins loaded:
    └─→ Show warning messagebox → RETURN
    ↓
  Set running = True
    ↓
  Run test in background thread
    ↓
  threading.Thread(target=run_test_all).start()
    |
    ├─→ test_handler.running = True
    |
    ├─→ Initialize counters:
    |     ├─→ total_pins = len(pins)
    |     ├─→ pass_count = 0
    |     ├─→ fail_count = 0
    |     └─→ skip_count = 0
    |
    ├─→ FOR each pin in pins:
    |     |
    |     ├─→ IF stop requested:
    |     |     └─→ BREAK (stop testing)
    |     |
    |     ├─→ Clear pin's previous test result
    |     |
    |     ├─→ Execute test based on pin.Type
    |     |     └─→ Same as single pin test flow
    |     |
    |     ├─→ Update pin's test result
    |     |
    |     ├─→ Update UI row
    |     |
    |     ├─→ Update counters (pass/fail/skip)
    |     |
    |     └─→ Log individual test result
    |
    ├─→ Log summary:
    |     └─→ "Test All Complete: {pass_count} passed, {fail_count} failed, {skip_count} skipped"
    |
    ├─→ set running = False
    |
    └─→ Display completion messagebox

3.3 I-BIT TEST FLOW:

USER CLICKS "I-BIT":
  app.on_i_bit()
    ↓
  Open File Dialog (select Excel file)
    ↓
  Load pins from Excel file
    ↓
  Set running_ibit = True
    ↓
  Run I-bit test in background thread
    ↓
  threading.Thread(target=run_i_bit_test).start()
    |
    ├─→ test_handler.running_ibit = True
    |
    ├─→ LOOP INDEFINITELY:
    |     |
    |     ├─→ FOR each pin in pins:
    |     |     |
    |     |     ├─→ IF stop requested:
    |     |     |     └─→ BREAK (stop I-bit)
    |     |     |
    |     |     ├─→ Execute test based on pin.Type
    |     |     |
    |     |     ├─→ Update pin's test result
    |     |     |
    |     |     └─→ Update UI row
    |     |
    |     ├─→ Log cycle completion: "I-bit cycle {cycle_num} complete"
    |     |
    |     ├─→ Sleep 1 second between cycles
    |     |
    |     └─→ IF stop requested: BREAK
    |
    ├─→ set running_ibit = False
    |
    └─→ Log "I-bit test stopped"

4. HARDWARE COMMUNICATION FLOW
================================================================================

4.1 SERIAL COMMUNICATION (Controllino/Arduino):

APPLICATION → CONTROLLINO:
  
  DIGITAL WRITE:
    hardware.digital_write(port, value)
      ↓
    Acquire thread lock (_lock)
      ↓
    Build command: "W,{port},{1 or 0}\n"
      ↓
    serial.write(cmd.encode('utf-8'))
      ↓
    Read response: serial.readline()
      ↓
    IF response == "OK:W":
      ├─→ Log success: "Digital Write: Pin D{port} -> {HIGH/LOW}"
      └─→ Release lock
    ELSE:
      ├─→ Log error: "Failed to write to D{port}: {response}"
      └─→ Release lock

  ANALOG READ:
    hardware.analog_read(port)
      ↓
    Acquire thread lock (_lock)
      ↓
    Build command: "R,{port}\n"
      ↓
    serial.write(cmd.encode('utf-8'))
      ↓
    Read response: serial.readline()
      ↓
    IF response starts with "OK:R":
      ├─→ Parse voltage: float(response.split(',')[1])
      ├─→ Log: "Analog Read: Pin A{port} -> {voltage}V"
      ├─→ Release lock
      └─→ RETURN voltage
    ELSE:
      ├─→ Log error: "Failed to read from A{port}: {response}"
      ├─→ Release lock
      └─→ RETURN 0.0

  CONTROLLINO SERIAL PROTOCOL (ControllinoSerialInterface.ino):
    Commands:
      - Ping: "?\n" → Response: "OK"
      - Digital Write: "W,{port},{value}\n" → Response: "OK:W,{port},{value}"
      - Analog Read: "R,{port}\n" → Response: "OK:R,{port},{voltage}"

4.2 SIMULATION MODE:

IF settings['Board']['simulation'] == True:
  |
  ├─→ Hardware connection attempted but not required
  |
  ├─→ Digital write operations: No-op (silently ignored)
  |
  └─→ Analog read operations: Return predefined values
        ├─→ Base voltage = 6.7V
        ├─→ Random variation: ±0.1V
        └─→ RETURN simulated voltage

5. MUX MATRIX CONTROL FLOW
================================================================================

PURPOSE: Route connector pins through multiplexer matrix to measurement pins

MUX BIT SETTING FLOW:
  
  set_mux_bits(hardware, bit_list)
    |
    ├─→ Parse bit_list: ["D0", "D5", "D12"]
    |
    ├─→ FOR each bit in bit_list:
    |     |
    |     ├─→ Extract port number (e.g., "D5" → 5)
    |     |
    |     └─→ hardware.digital_write(port, True)
    |           └─→ Set digital output HIGH (5V)
    |
    └─→ Log: "Mux matrix configured: {bit_list}"

MUX BIT CLEARING FLOW:
  
  clear_mux_bits(hardware, bit_list)
    |
    ├─→ FOR each bit in bit_list:
    |     └─→ hardware.digital_write(port, False)
    |           └─→ Set digital output LOW (0V)
    |
    └─→ Log: "Mux matrix cleared: {bit_list}"

CONNECTOR PIN TO MUX BITS MAPPING:
  
  connector_pin_to_bits(connector_id, hardware, connector_mapping)
    |
    ├─→ Parse connector ID: "J1-15" → connector="J1", pin=15
    |
    ├─→ Look up in connector_mapping DataFrame:
    |     └─→ Query: connector_mapping[
    |           (connector_mapping['Connector'] == 'J1') &
    |           (connector_mapping['Pin'] == 15)
    |         ]
    |
    ├─→ Extract mux control bits from row
    |     └─→ Columns: D0, D1, D2, ... D15 (binary 1/0)
    |
    ├─→ Build bit_list: ["D2", "D7", "D12"] (where value=1)
    |
    └─→ RETURN bit_list

TYPICAL TEST USAGE:
  
  1. Get pin pair info:
     pair_info = get_pin_pair_info_controlino(pin.Id, hardware)
       └─→ Returns: (voltage_measure_pin, card_enable_bits, mux_bits)
  
  2. Configure mux matrix:
     set_mux_bits(hardware, mux_bits)
       └─→ Routes connector pin to measurement circuit
  
  3. Enable card outputs (if needed):
     enable_cards(hardware, card_enable_bits)
       └─→ Activates IO cards for signal injection
  
  4. Perform measurement:
     voltage = measurer.measure_voltage(analog_port)
       └─→ Reads voltage through configured mux path
  
  5. Clear mux matrix:
     clear_mux_bits(hardware, mux_bits)
       └─→ Resets mux to default state

6. VOLTAGE MEASUREMENT FLOW
================================================================================

HIGH-LEVEL FLOW:
  
  measurer.measure_voltage(analog_port, duration, sample_interval)
    |
    ├─→ Check simulation mode:
    |     |
    |     ├─→ IF simulation == True:
    |     |     ├─→ Return simulated voltage (6.7V ± random)
    |     |     └─→ Skip hardware read
    |     |
    |     └─→ IF simulation == False:
    |           └─→ Continue to real measurement
    |
    ├─→ Initialize readings list
    |
    ├─→ Calculate end_time = start_time + duration
    |
    ├─→ SAMPLING LOOP:
    |     |
    |     WHILE time.time() < end_time:
    |       |
    |       ├─→ hardware.analog_read(analog_port)
    |       |     └─→ Read voltage from Arduino ADC
    |       |
    |       ├─→ Append reading to readings list
    |       |
    |       ├─→ Calculate remaining_time
    |       |
    |       └─→ IF remaining_time > sample_interval:
    |             └─→ sleep(sample_interval)
    |
    ├─→ Apply voltage scaling:
    |     └─→ scale_factor = settings['scale']['voltage']
    |
    ├─→ Calculate average:
    |     └─→ average_voltage = mean(readings) * scale_factor
    |
    └─→ RETURN average_voltage

MEASUREMENT PARAMETERS (from settings.yaml):
  - duration: 3.0 seconds (default sampling period)
  - sample_interval: 0.1 seconds (100ms between samples)
  - scale_factor: Voltage divider or ADC calibration (default: 1.0)

EXAMPLE USAGE IN TEST:
  
  # Power test measurement
  voltage = test_handler.measure_voltage(
      pin_id="J1-15",
      analog_port=0,  # A0
      idx=0
  )
    ↓
  measurer.measure_voltage(analog_port=0)
    ↓
  RETURN 24.3V (example)

7. UDP CARD CONTROL FLOW
================================================================================

PURPOSE: Control external IO cards via UDP protocol for signal injection

7.1 UDP CARD INITIALIZATION:

UDPCardManager() initialization
  |
  ├─→ Load settings from settings.yaml
  |
  ├─→ Read CardSettings section:
  |     └─→ For each card (C1-C7):
  |           ├─→ enabled: true/false
  |           ├─→ send_ip: "192.168.1.101"
  |           ├─→ send_port: 6000
  |           ├─→ receive_ip: "192.168.1.100"
  |           └─→ receive_port: 7000
  |
  ├─→ Create UDPSender instances for enabled cards
  |     └─→ UDPSender(card_id, send_ip, send_port, receive_ip, receive_port)
  |
  └─→ start_all()
        |
        ├─→ FOR each card:
        |     ├─→ Create UDP socket
        |     ├─→ Bind to receive_ip:receive_port
        |     ├─→ Start background thread for receiving data
        |     └─→ IF binding fails: Collect error message
        |
        └─→ RETURN list of binding errors (or empty list)

7.2 DIGITAL OUTPUT CONTROL:

card_manager.set_digital_output(card_id=2, do_number=5, state=True)
  |
  ├─→ Get card instance: card = cards[2]
  |
  ├─→ card.set_digital_output(5, True)
  |     |
  |     ├─→ Build UDP message:
  |     |     └─→ Format: "DO5=1" (or "DO5=0" for False)
  |     |
  |     ├─→ Send UDP packet:
  |     |     └─→ socket.sendto(message, (send_ip, send_port))
  |     |
  |     └─→ Log: "Card C2: Set DO5 = HIGH"
  |
  └─→ RETURN True (success)

7.3 ANALOG OUTPUT CONTROL:

card_manager.set_analog_output(card_id=3, ao_number=2, voltage=10.0)
  |
  ├─→ Get card instance: card = cards[3]
  |
  ├─→ card.set_analog_output(2, 10.0)
  |     |
  |     ├─→ Build UDP message:
  |     |     └─→ Format: "AO2=10.0"
  |     |
  |     ├─→ Send UDP packet:
  |     |     └─→ socket.sendto(message, (send_ip, send_port))
  |     |
  |     └─→ Log: "Card C3: Set AO2 = 10.0V"
  |
  └─→ RETURN True (success)

7.4 DIGITAL INPUT QUERY:

card_manager.get_digital_input(card_id=4, di_number=8)
  |
  ├─→ Get card instance: card = cards[4]
  |
  ├─→ card.get_digital_input(8)
  |     |
  |     ├─→ Build UDP query:
  |     |     └─→ Format: "DI8?"
  |     |
  |     ├─→ Send UDP packet
  |     |
  |     ├─→ Wait for response (timeout: 1 second)
  |     |     └─→ Background thread receives: "DI8=1"
  |     |
  |     ├─→ Parse response: state = True
  |     |
  |     └─→ Log: "Card C4: DI8 = HIGH"
  |
  └─→ RETURN True (or False)

7.5 LOCALHOST MODE:

IF settings['CardSettings']['localhost'] == True:
  |
  ├─→ Override all card IPs to "127.0.0.1"
  |
  ├─→ Use localhost_simulator for card responses
  |
  └─→ Simulates UDP cards on local machine

TYPICAL USAGE IN POWER TEST:
  
  # Parse Power_Input: "C2_AO2V10"
  card_num = 2
  event_type = "AO"
  event_num = 2
  value = 10.0
  
  # Set analog output
  card_manager.set_analog_output(card_num, event_num, value)
  
  # Wait for stabilization
  time.sleep(0.3)
  
  # Measure voltage
  voltage = measurer.measure_voltage(analog_port)
  
  # Clear output
  card_manager.set_analog_output(card_num, event_num, 0.0)

================================================================================

8.1 LOAD BUTTON:
  User clicks "Load"
    ↓
  app.on_load()
    ↓
  Open file dialog (select Excel file)
    ↓
  Load pins from Excel
    ↓

    ↓

8.2 KEEP-ALIVE BUTTON:
  User clicks "Keep-Alive"
    ↓
  app.on_keep_alive()
    |
    ├─→ IF not currently pulsing:
    |     |
    |     ├─→ keep_alive.start_pulsing()
    |     |     |
    |     |     ├─→ Start background thread
    |     |     |
    |     |     └─→ LOOP INDEFINITELY:
    |     |           |
    |     |           ├─→ hardware.digital_write(KEEPALIVE_PIN, True)
    |     |           ├─→ sleep(0.5)
    |     |           ├─→ hardware.digital_write(KEEPALIVE_PIN, False)
    |     |           ├─→ sleep(0.5)
    |     |           └─→ IF stop_pulsing: BREAK
    |     |

    |     |
    |     └─→ Log: "Keep-Alive pulsing started"
    |
    └─→ ELSE (already pulsing):
          |
          ├─→ keep_alive.stop_pulsing()
          |
          ├─→ Update button: text="Keep-Alive", color=default
          |
          └─→ Log: "Keep-Alive pulsing stopped"

8.3 NEXT BUTTON (Debug Mode):
  User clicks "Next"
    ↓
  app.on_next()
    ↓
  next_event.set()
    ↓

  |
  ├─→ initialize_hardware(settings)

  |           |     ├─→ Log warning: "Failed to connect to {port}"
  |           |     ├─→ Log: "Running in no-connection mode"
  |           |     └─→ Continue (hardware.connected = False)
  |           |
  |           └─→ IF simulation == False:

  |                 ├─→ save_settings(settings)

  |
  ├─→ hardware.digital_write(port, value)

  |     ├─→ Display error messagebox:

13. POWER TEST DETAILED FLOW (EXAMPLE)
================================================================================

POWER TEST PROCEDURE:

test_handle.run_power_test(pin)
  |
  ├─→ INITIALIZATION:
  |     ├─→ Extract pin parameters:
  |     |     ├─→ pin.Id = "J1-15"
  |     |     ├─→ pin.Power_Expected = "24V"
  |     |     ├─→ pin.Power_Input = "C2_AO2V10"
  |     |     └─→ pin.Pair = "J1-16"
  |     |
  |     ├─→ Check simulation mode
  |     |
  |     └─→ IF debug mode: wait_debug(100, "active")
  |
  ├─→ GET PIN PAIR INFO:
  |     └─→ get_pin_pair_info_controlino(pin.Id, hardware)
  |           ├─→ Query connector mapping Excel
  |           ├─→ Extract: voltage_measure_pin (A0)
  |           ├─→ Extract: card_enable_bits (["D20", "D21"])
  |           ├─→ Extract: mux_bits (["D2", "D7", "D12"])
  |           └─→ RETURN (A0, ["D20", "D21"], ["D2", "D7", "D12"])
  |
  ├─→ CONFIGURE MUX MATRIX:
  |     └─→ set_mux_bits(hardware, ["D2", "D7", "D12"])
  |           ├─→ hardware.digital_write(2, True)
  |           ├─→ hardware.digital_write(7, True)
  |           └─→ hardware.digital_write(12, True)
  |
  ├─→ ENABLE CARDS:
  |     └─→ enable_cards(hardware, ["D20", "D21"])
  |           ├─→ hardware.digital_write(20, True)
  |           └─→ hardware.digital_write(21, True)
  |
  ├─→ INITIAL MEASUREMENT (Before stimulus):
  |     └─→ voltage_initial = measure_voltage("J1-15", A0, idx=0)
  |           └─→ measurer.measure_voltage(0)
  |                 └─→ RETURN 0.1V (near 0V)
  |
  ├─→ CHECK IF POWER INPUT REQUIRED:
  |     |
  |     ├─→ IF pin.Power_Input == "none" or empty:
  |     |     |
  |     |     ├─→ Compare voltage_initial to Power_Expected
  |     |     |
  |     |     ├─→ Parse Power_Expected: 24V
  |     |     |
  |     |     ├─→ Calculate tolerance: 24V ± 2V (default 2V)
  |     |     |
  |     |     ├─→ IF 22V <= voltage_initial <= 26V:
  |     |     |     ├─→ result = "PASS"
  |     |     |     └─→ message = "Voltage within tolerance"
  |     |     |
  |     |     └─→ ELSE:
  |     |           ├─→ result = "FAIL"
  |     |           └─→ message = "Voltage out of tolerance"
  |     |
  |     └─→ ELSE (Power_Input specified):
  |           |
  |           ├─→ Verify initial voltage is ~0V:
  |           |     └─→ IF voltage_initial > 1V:
  |           |           ├─→ result = "FAIL"
  |           |           └─→ message = "Unexpected voltage before stimulus"
  |           |
  |           ├─→ Parse Power_Input "C2_AO2V10":
  |           |     ├─→ card_num = 2
  |           |     ├─→ event_type = "AO"
  |           |     ├─→ event_num = 2
  |           |     └─→ value = 10.0
  |           |
  |           ├─→ IF debug mode: wait_debug(101, "active")
  |           |
  |           ├─→ ACTIVATE CARD OUTPUT:
  |           |     |
  |           |     ├─→ IF event_type == "AO":
  |           |     |     └─→ card_manager.set_analog_output(2, 2, 10.0)
  |           |     |           └─→ UDPSender(C2).send("AO2=10.0")
  |           |     |
  |           |     └─→ IF event_type == "DO":
  |           |           └─→ card_manager.set_digital_output(2, 2, True)
  |           |                 └─→ UDPSender(C2).send("DO2=1")
  |           |
  |           ├─→ WAIT FOR STABILIZATION:
  |           |     └─→ time.sleep(0.3)  # 300ms
  |           |
  |           ├─→ IF debug mode: wait_debug(102, "active")
  |           |
  |           ├─→ MEASURE VOLTAGE (After stimulus):
  |           |     └─→ voltage_final = measure_voltage("J1-15", A0, idx=1)
  |           |           └─→ measurer.measure_voltage(0)
  |           |                 └─→ RETURN 24.3V
  |           |
  |           ├─→ DEACTIVATE CARD OUTPUT:
  |           |     |
  |           |     ├─→ IF event_type == "AO":
  |           |     |     └─→ card_manager.set_analog_output(2, 2, 0.0)
  |           |     |
  |           |     └─→ IF event_type == "DO":
  |           |           └─→ card_manager.set_digital_output(2, 2, False)
  |           |
  |           ├─→ COMPARE TO EXPECTED:
  |           |     |
  |           |     ├─→ Parse Power_Expected: 24V
  |           |     |
  |           |     ├─→ Calculate tolerance: 24V ± 2V
  |           |     |
  |           |     ├─→ IF 22V <= voltage_final <= 26V:
  |           |     |     ├─→ result = "PASS"
  |           |     |     └─→ message = "Voltage within tolerance (24.3V)"
  |           |     |
  |           |     └─→ ELSE:
  |           |           ├─→ result = "FAIL"
  |           |           └─→ message = "Voltage out of tolerance (24.3V vs 24V±2V)"
  |           |
  |           └─→ IF debug mode: wait_debug(103, "done")
  |
  ├─→ CLEANUP:
  |     ├─→ clear_mux_bits(hardware, ["D2", "D7", "D12"])
  |     └─→ clear_bits(hardware, ["D20", "D21"])
  |
  └─→ RETURN (voltage_final, success, message)
        └─→ (24.3, True, "Voltage within tolerance (24.3V)")
