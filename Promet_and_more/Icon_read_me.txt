; Simple placeholder icon file reference
; To use a custom icon:
; 1. Create or obtain a .ico file (256x256 recommended, with multiple sizes: 16x16, 32x32, 48x48, 256x256)
; 2. Save it as "icon.ico" in the project root directory
; 3. The installer.iss file already references it
;
; Free icon resources:
; - Icons8: https://icons8.com/icons
; - Flaticon: https://www.flaticon.com/
; - Icon Archive: https://iconarchive.com/
;
; Online icon converters (PNG to ICO):
; - https://convertio.co/png-ico/
; - https://www.icoconverter.com/
; - https://cloudconvert.com/png-to-ico
;
; Until you add a custom icon, comment out the SetupIconFile line in installer.iss
